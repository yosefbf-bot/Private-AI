## Changes by function

**Saved-source search:** one on-demand authorization-aware word-search view reuses existing encrypted records and Library passage search. It searches chats, notes/drafts, meetings, projects, documents, canonical tasks and retained job metadata/drafts. Collection filtering excludes unknown/unrelated membership. Dedicated clinical sources require explicit opt-in; ordinary saved text can also contain PHI. No second index or global PHI pool is created. Bounded source counts, lower bounds and coverage are visible. Results navigate to existing chat, note, meeting, project, Library, task, run and clinical views; missing sources fail visibly. Completed report bodies must be imported into Library to search their contents.

**Source review and privacy assistance:** Library files have collapsible source dates/version/review metadata, source-change revisions and local-calendar review deadlines. A missing date stays unknown; upload time does not prove currency. Owner attestation is never independent approval proof. Existing semantic citations carry the same review state and reject stale review changes without rebuilding identical vectors. Identifier suggestions and optional manual ranges produce selected redacted copies only. Source and selection are revalidated before clipboard copying. Original text/bytes, project links and privacy permissions remain unchanged; this is not a de-identification guarantee. A confirmed legacy-project missing-file-links scope widening bug was fixed.

**Correspondence:** optional deterministic keyword/explicit-unread review uses approved cached WhatsApp messages and explicitly opted-in selected Outlook snapshots. Native Outlook caching happens only after both read-grant checks. Recurring review shares the existing Worker cadence on primary/worker roles and yields to foreground jobs, background work, app lock and pause. It makes no Inbox, provider or browser request. Owners, deadlines and reply status remain unknown until reviewed. One source creates one canonical capture/follow-up with internal drafts; repeated review does not clone work or change an existing deadline. Dismissal changes only the suggestion. No sending, deletion, forwarding or automatic mailbox modification is added.

**One Dashboard:** source-linked administrative notices for failed jobs/schedules and unresolved delivery records join existing tasks/clinical alerts. Acknowledgment/snooze updates only notice metadata; it never resolves a clinical alert, completes a task or retries a message. Source changes re-arm review. Correspondence saves refresh the same Dashboard. Deferred-save and clinical source-load races were fixed with generation checks.

**Recovery/publication:** prior reliability fixes are preserved. Desktop PR #18 and Android PR #3 were merged only after current exact-head GitHub checks passed. Android's two acceptance fixture races were corrected without changing production authentication. Local main pointers/checkouts were safely synchronized. Five verified obsolete/identical local targets (~2.49 GiB) and fully merged review branches were removed; current delivery, latest recovery, native/model inputs, signers and unique evidence remain. Workspace links were corrected. The dated current-assignment authorization preserves separate branches/PRs and exact-head gates.
